# AI-Powered Data Validation Pipeline (RAG-Based)

## Overview
This project implements a Retrieval-Augmented Generation (RAG) based 
data validation pipeline using OpenAI embeddings and LLM reasoning.

## Features
- Data cleaning using Pandas
- Rule embedding with OpenAI embeddings
- Cosine similarity-based rule retrieval
- LLM-powered intelligent validation
- Structured logging
- Defensive error handling

## Tech Stack
- Python
- Pandas
- NumPy
- OpenAI API

## How It Works
1. Clean input dataset
2. Embed validation rules
3. Retrieve most relevant rule using cosine similarity
4. Validate row using LLM
5. Store validation result
